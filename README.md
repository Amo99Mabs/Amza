# Amza

A lightweight, recruiter‑facing chatbot interface built with **Node.js, HTML, CSS, and JavaScript**.  
Designed for clean UI/UX, responsive layout, and easy deployment.

---

## 🚀 Features
- Simple chatbot widget styled to match portfolio theme
- Responsive design for desktop and mobile
- Modular file structure (frontend + backend separation)
- Recruiter‑friendly commit hygiene and documentation
